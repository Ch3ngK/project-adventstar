# AdventStar

## Overview

AdventStar is a modern AI-powered B2B uniform supplier platform based in Singapore.

The platform is designed to help businesses discover, customize, and order uniforms while giving the company internal tools to manage quotations, customers, orders, and production.

Unlike a traditional catalogue website, AdventStar should feel like a premium software product that showcases the company's manufacturing capabilities while leveraging AI to improve the customer experience.

---

# Brand Personality

The brand should feel:

* Premium
* Trustworthy
* Professional
* Modern
* Innovative
* Clean
* Confident
* Friendly

Avoid looking like a generic e-commerce store.

Think:

* Apple
* Stripe
* Linear
* Vercel
* Notion

rather than Alibaba or Taobao.

---

# Target Customers

AdventStar supplies uniforms for:

* Corporate offices
* Construction companies
* Manufacturing
* Hospitality
* Healthcare
* Schools
* Security
* Logistics
* Government organizations

The design should appeal to business decision makers rather than consumers.

---

# Design Language

Use:

* lots of whitespace
* large typography
* subtle gradients
* premium photography
* soft shadows
* rounded corners
* glassmorphism where appropriate
* smooth animations
* clean layouts

Avoid:

* clutter
* bright colours
* childish icons
* excessive borders
* loud gradients
* template-looking sections

* slide
* scale
* staggered reveals
* parallax
* hover elevation

Never overuse animations.

# UI Principles

Every page should answer:

Is it premium?

Is it trustworthy?

Would a $100M manufacturing company proudly use this?

If the answer is no, redesign it.

---

# Expectations

Before generating UI:

1. Think about user experience.

2. Think about hierarchy.

3. Think about spacing.

4. Think about responsiveness.

5. Think about accessibility.

6. Think about animation.

7. Think about maintainability.

Do not simply generate code.

Design first.

Then implement.

Aim for production-quality software.

## Important Design Rule

AdventStar should look premium but simple.

Avoid visual clutter.

Do not overuse:
- gradients
- floating cards
- glassmorphism
- animated blobs
- excessive shadows
- too many icons
- too many sections
- overlapping layouts

The site should feel like a modern B2B uniform supplier, not a flashy SaaS landing page.

When in doubt, choose clarity over decoration.
